🔄 End-to-End Data Flow

Triage → Ground → Assemble → Draft → Verify → Approve → Track → Learn
1. Browser → web (POST /api/full-pipeline) — PHI Guard scans, then Patient Advocate + Denial Triage run → creates Case + Denial + traces + Gate 1
2. Human approves Gate 1 → web runs Policy Research + Evidence Assembly + Letter Drafting (calls agents for live Gemini) → Quality Review (adversarial 7-check) → Gate 2
3. agents → Vertex AI (gemini-3.6-flash, global endpoint) via runtime SA metadata token → returns structured triage + appeal letter
4. Every step emits a DecisionTraceEvent → trace-stream (Socket.io) → browser live feed
5. Human approves Gate 2 → appeal submitted → Outcome Learning updates evidence weights (Firestore → SQLite fallback)
